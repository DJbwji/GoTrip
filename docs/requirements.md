# Соответствие техническому заданию
| Требование | Реализация |
|---|---|
| Python 3.10+, Django 4/5, SSR | Django 5.2, Python 3.12 при проверке, Django Templates |
| SQLite / PostgreSQL | SQLite по умолчанию; PostgreSQL через переменные среды |
| Минимум 5–7 страниц | Главная, каталог, экскурсия, поездки, поездка, гиды, гид, вход, регистрация, кабинет, профиль, чат, модерация, о проекте |
| Авторизация и роли | users.User, GuideApplication; login_required, owner-фильтры, staff-проверка |
| Полный CRUD | tours и trips |
| Связи БД | FK: экскурсия–гид, дата–экскурсия; M2M: категории, избранное, участники; O2O: профиль, заявка гида |
| Django Admin | Все предметные модели с list_display/search_fields/list_filter |
| Блок А: минимум 3 | Все 5: пагинация, фильтры/сортировка, поиск, детали со связями, категории |
| Блок Б: минимум 2 | Все 5: профиль, отзывы, избранное, история, восстановление пароля |
| Блок В: минимум 1 | 3: изображения/Pillow, email, AJAX-избранное |
| Наследование | base.html; страницы extends, переиспользуемые includes |
| Адаптивность | CSS breakpoints 1150/900/600, мобильное меню и нижняя навигация |
| Статика и медиа | STATIC_URL, STATICFILES_DIRS, STATIC_ROOT, MEDIA_URL, MEDIA_ROOT |
| Django Forms | ModelForm, inline formsets, валидация clean и clean_<field> |
| HTML5-валидация | required, email, date, number, min/max, maxlength |
| Структура | 7 предметных Django-приложений |
| Модели | __str__, Meta, verbose_name, ordering, related_name |
| URL | app_name, reverse, reverse_lazy, get_absolute_url, template url |
| Защита | CSRF, ORM, экранирование шаблонов, проверки ролей и владельцев, POST-мутации |
| Заявки гидов | pending / approved / rejected / revision; повторная подача |
| Модерация каждой экскурсии | draft → pending → approved / rejected / revision; каталог только approved |
| Email модератору | Новые экскурсии, заявки гидов, жалобы; console или SMTP |
| Жалобы | Только после оплаченной экскурсии, очередь и ответ модератора |
| Бронирование | Остаток мест, серверная цена, атомарные обновления, отмена |
| Оплата | Отдельный переход и тестовое подтверждение; реальный провайдер требует подключения |
| Поиск попутчиков | Публичные поездки, даты, вместимость, список участников |
| Личный чат | Уникальный диалог туриста с гидом, проверка участников |
| Ранги | Вычисляются из завершённых бронирований / опубликованных экскурсий |

Стандартные служебные маршруты /admin/, /static/, /media/ задаются в конфигурации. Пользовательские навигационные ссылки формируются через именованные маршруты.
