# GitHub и дальнейшие изменения

Исходный проект находится в папке diploma. Репозиторий хранит код, шаблоны, миграции и локальные статические фотографии. Рабочая SQLite-база, пользовательские фотографии, .env, виртуальное окружение и резервные копии исключены из Git.

## Первая загрузка
В GitHub создайте репозиторий gotrip в своём аккаунте. Для первой загрузки через подключённое приложение включите Add README, чтобы появилась ветка main. Репозиторий можно оставить приватным. После создания передайте ссылку в чат — код можно загрузить через подключённый GitHub без передачи пароля.

На компьютере уже может быть подготовлен начальный коммит. После подключения origin дальнейшая работа через обычный Git:
```powershell
git status
git add .
git commit -m "Describe the change"
git push
```

Эти команды требуют авторизованного Git. Подключение GitHub в чате и авторизация установленного Git — разные способы доступа.

## Проверки
GitHub Actions запускает конфигурационные проверки, проверку миграций и тесты на Python 3.10 и 3.12 после отправки изменений в main и при создании pull request.

Локально:
```powershell
.venv/Scripts/python.exe manage.py check
.venv/Scripts/python.exe manage.py test
```

## Публикация сайта
GitHub хранит исходный код. GitHub Pages не выполняет Django и не подходит для полного GoTrip с авторизацией, бронированиями и базой данных.

Для постоянного адреса требуется отдельный Python-хостинг. При подключении репозитория к хостингу изменения в main могут автоматически запускать обновление сайта, сохраняя его адрес. База и пользовательские загрузки должны храниться постоянно и отдельно от исходного кода.

До публичного запуска необходимо настроить production-сервер, HTTPS, раздачу static/media, секретный ключ, резервное копирование и собственные пароли администратора. Команда seed_demo предназначена только для локальной демонстрации; опубликованный пароль из README не используют для публичного администратора.
