# Бесплатная публикация GoTrip на PythonAnywhere

Выбранный вариант сохраняет Django, SQLite и загруженные фотографии на хостинге. Компьютер пользователя после публикации не нужен. Бесплатное приложение необходимо продлевать кнопкой на вкладке Web раз в месяц.

## Установка

1. Создайте бесплатный аккаунт: https://www.pythonanywhere.com/registration/register/beginner/
2. Откройте Account → API Token и сгенерируйте токен. Он остаётся внутри PythonAnywhere; не отправляйте его в чат и не добавляйте в GitHub.
3. Откройте НОВУЮ Bash-консоль на вкладке Consoles. Новая консоль нужна, чтобы PythonAnywhere предоставил токен в переменной API_TOKEN.
4. Вставьте одну команду:

```bash
curl -fsSL https://raw.githubusercontent.com/DJbwji/GoTrip/main/deploy/pythonanywhere-install.sh -o /tmp/gotrip-install.sh && bash /tmp/gotrip-install.sh
```

5. Когда Django предложит создать администратора GoTrip, выберите username, email и отдельный пароль для сайта. Это НЕ пароль аккаунта хостинга. Пароль при вводе не отображается — так и должно быть.
6. После сообщения об успешном reload откройте адрес, показанный установщиком. Дождитесь загрузки сайта и проверьте главную, вход, каталог и бронирование.

Если аккаунт зарегистрирован на EU-сервере, добавьте к команде запуска `--host eu.pythonanywhere.com`. Для основного www-сервера никаких параметров не требуется.

## Что делает установщик

- Получает исходники только из https://github.com/DJbwji/GoTrip .
- Создаёт виртуальное окружение и устанавливает Django и Pillow.
- Генерирует уникальный секрет, выключает DEBUG, ограничивает домен и включает HTTPS.
- Хранит SQLite и пользовательские фотографии в приватном каталоге `~/.gotrip-data`, отдельно от репозитория.
- Применяет миграции и собирает статические файлы.
- Создаёт публичный демонстрационный каталог с 12 опубликованными экскурсиями. У примерных пользователей отключён вход; общего опубликованного пароля администратора нет.
- Предлагает создать личного администратора сайта.
- Настраивает WSGI и раздачу /static/ и /media/ через серверы PythonAnywhere.
- Отправляет команду перезагрузки сайта через официальный API.

Если в аккаунте уже размещён другой проект, установщик останавливается и сохраняет существующую конфигурацию.

## Обновления после изменений в GitHub

В Bash-консоли PythonAnywhere:

```bash
~/.virtualenvs/gotrip/bin/python ~/gotrip/deploy/pythonanywhere.py --update
```

Для EU-сервера добавьте `--host eu.pythonanywhere.com`.

Обновление использует git pull --ff-only, делает резервную копию базы перед миграциями, сохраняет .env, базу, пользователей и фотографии. Если на сервере вручную меняли код, сначала сохраните изменения в Git; установщик не перезаписывает их.

Автоматическая публикация по push пока не подключена: обновление запускается приведённой командой. Это позволяет обойтись без хранения токена PythonAnywhere в GitHub Actions и ограничений бесплатных фоновых задач.

## Ограничения бесплатного размещения

Приложение нужно продлевать раз в месяц на вкладке Web. Консольная почта и тестовая оплата сохраняются; реальный SMTP нужно настроить отдельно с учётом сетевых правил хостинга. Первый запуск/обновление требует доступной CPU-квоты аккаунта. В установщике нет оплаты или перехода на платный тариф.
